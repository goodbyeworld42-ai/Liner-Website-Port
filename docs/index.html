A port, not a client

No Electron. No installer. No wrapper.

There is no desktop binary behind this and no webview pointed at one. The renderer was rebuilt for the browser, and every part of the desktop layer was replaced with a web-native equivalent.

Electron → browser

Main-process windows and IPC are gone. A thin Next.js shell serves the bundle and hosts the API relays.

Filesystem → IndexedDB

Likes, playlists, history and cached covers live in linerDb, on your device, in the browser.

IPC → API relays

Playback, presence and translation run through /api/* routes instead of native handlers.
